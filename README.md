# City Policy Lite

Create a minimal React + TypeScript + Vite + Tailwind app called "City Policy Crash-Test". Only a single placeholder page with the title "City Policy Crash-Test" and the line "Frontend coming from GitHub". No backend, no Supabase, no authentication, no database. Install the npm package maplibre-gl. Keep the styling plain; the real UI will be pushed through GitHub.
